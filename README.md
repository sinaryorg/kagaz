## ✨ Features

- **🚀 Lightning Fast Desktop App**: Built on top of Electron + Vite for smooth, responsive performance.
- **🎨 Minimalist & Intuitive UI**: Distraction-free workspace tailored for notes, knowledge management, and fast editing.
- **📄 Rich Markdown & Knowledge Organization**: Seamlessly organize notes, folders, and linked context.
- **⚡ Modern Tech Stack**: Powered by React 19, TypeScript, Lucide Icons, and Tailwind CSS.
- **📦 Cross-Platform Package Build**: Build native Windows executables (NSIS installer & portable app).

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) or [pnpm](https://pnpm.io/)
- [Git](https://git-scm.com/)

### Installation & Local Development

1. **Clone the Repository**
   ```bash
   git clone https://github.com/sinaryorg/kagaz.git
   cd kagaz
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Environment**
   To launch Vite dev server alongside Electron in hot-reload mode:
   ```bash
   npm run app
   ```

   Or run just the Web UI in browser mode:
   ```bash
   npm run dev
   ```

4. **Build Production Executable**
   ```bash
   npm run dist
   ```
   The generated installers and binaries will be stored in the `release/` folder.
